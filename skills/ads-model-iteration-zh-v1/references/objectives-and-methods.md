# 优化目标与方法

当问题涉及建模目标选择、常见方法类别或方法取舍时，读取本文件。

## 首要原则

稳定的优化顺序是：

1. 明确业务场景；
2. 确定建模目标；
3. 构造样本与特征；
4. 最后再选择模型结构。

这一顺序很重要，因为更强的网络只会放大错误的目标定义。

## 目标选择

### 面向排序的目标

广告排序不只是单独优化 CTR 或 CVR。

- 平台价值与 `ecpm` 密切相关；
- 用户体验还会受到隐藏成本、频控、相关性、负反馈及相关因素的调整。

一种实用表达是：

- `sorted ecpm = ecpm + hidden cost`

因此，目标设计应体现业务价值与体验约束，而不只是原始点击预测。

### CTR / CVR / PVR

经典目标包括：

- `CTR`
- `CVR`
- `PVR` 或 send-to-convert 风格的目标

一个重要的实践点：

- 直接建模 `PVR` 并不自动优于 `CTR * CVR`；
- 系统历史、计费机制、可解释性和稳定性都会影响哪种选择更合适。

### 深度转化与更长周期的价值

许多广告系统并非单任务系统。

常见的目标组合包括：

- `CTR`
- `CVR`
- `Deep CVR`
- `VO`
- `LTV`

这也是广告领域常用多任务学习的原因之一。

## 关键建模问题

### CTR 实际表示什么

业务上的物理含义是：

- `show -> click`

但实际建模中的 CTR 往往更接近：

- `send -> click`

这会带来两个问题：

- CTR 可能混入展现率或可见机会的影响；
- 目标本身可能已经含有位置偏差或曝光偏差。

常见的后续思路：

- 将 CTR 拆成 `SSR * show2click`；
- 对用户是否实际看到广告单独建模。

### 如何处理延迟转化

对于深度转化、长周期价值和 `LTV`，延迟本身就是建模问题的一部分。

常见方法包括：

- `fast emit`
- 延迟分布建模
- 多窗口或分阶段的多任务目标

### 粗排是否应学习精排

常见选择包括：

- 使用 Learning to Rank 模仿精排顺序；
- 直接学习 `RECPM` 或 `ECPM`。

实践中的取舍：

- 学习精排有助于提升链路一致性；
- 但也可能继承精排的偏差与波动；
- 如果多个上游阶段都模仿同一个下游信号，正反馈环可能放大系统问题。

## 常见方法类别

### LTR

主要形式：

- point-wise
- pair-wise
- list-wise

典型用途：

- 粗排；
- 召回阶段学习下游顺序；
- 排序优化问题。

广告中的典型难点：

- 出价不容易纳入；
- 精排目标本身可能带偏；
- 链路中可能出现正反馈环。

### RECPM

核心思路：

- 不只学习点击或转化概率；
- 学习更接近业务价值的量。

其意义在于：

- 更接近业务目标；
- 通常更容易与考虑出价的逻辑结合。

### 多任务学习

常见广告任务组合：

- CTR；
- CVR；
- 深度转化；
- 长期价值；
- 辅助校准或辅助支持目标。

采用多任务学习的原因：

- 共享底层表示；
- 让高频目标支持低频目标；
- 让稀疏或延迟目标更容易学习。

### Feature Mask

核心思路：

- 训练时随机丢弃部分特征；
- 降低模型对强但泛化能力弱的 ID 特征的过度依赖。

其意义在于：

- 有助于泛化；
- 常用于冷启动和鲁棒性提升；
- 也可支持对比式训练设置。

### Meta Learning

广告中的典型用途：

- 改善冷启动广告 embedding 的初始化。

其意义在于：

- 减轻新广告随机初始化造成的不稳定；
- 帮助新广告从信息更充分的表示起步。

### 聚类与相似广告迁移

核心思路：

- 利用相似且效果较好的广告帮助冷启动广告。

典型实现方式：

- 两阶段离线聚类；
- 端到端的类聚类表示学习。

### 不确定性建模

核心问题不只是“均值是否准确”，还包括“估计有多不确定”。

其意义在于：

- 有助于探索；
- 有助于流量分配；
- 在冷启动场景下尤其有助于风险控制。

## 方法选择指引

用户问“接下来该尝试什么”时，可按以下方式初步对应：

- 与排序不匹配：考虑 `LTR`；
- 与业务价值不匹配：考虑 `RECPM` 或其他面向价值的目标；
- 标签稀疏或延迟：考虑多任务学习；
- 冷启动：考虑泛化特征、`Feature Mask`、`Meta Learning`、聚类或不确定性建模；
- 预测偏差：考虑校准和目标定义复核。

在重述目标和可能的失败机制之前，不要直接推荐某类方法。
