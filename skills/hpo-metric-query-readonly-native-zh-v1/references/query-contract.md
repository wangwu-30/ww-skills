# 查询结果解释

当前 Job 提供的不可变输入及其说明是 Task 需求和观测上下文的依据；结果如何表示由该 Job 的输出 schema 决定。本说明提供查询方法与结果解释，不另行定义输入输出合同。

发现、查询语义与诊断请读[共用指南](metric-query/GUIDE.md)。把需求、解析身份、实际观测方式和结果分开。创建时明确必要固定身份与范围；运行时取得按已明确来源派生的本次身份和值。一次尝试采用新方法不会改写 Task 意图；发现固定事实错误时提出正式修改，不能自行猜测替换。

对于尚未解析的线索，沿其来源追查 namespace提示。数据新鲜度或先前推断不会绑定查询面；检查原始业务路径和实际定义，保留精确身份与约束。用户事实、直接观测和重要推断分别注明依据、出处及未验证部分，推断通过记忆/复盘仍保持性质。区分本次查询和有时间/范围的历史证据；确认另一项或报告被接收不等于确认全部推断。仅元数据、不完整预览或对其他需求成功的查询不能证明本需求已有读数。

对本 Job 提供的精确 Libra 原生查询身份，按[Libra 知识](metric-query/libra.md)使用冻结的 `native_query` 对象。其原生子命令、原始参数和响应行选择规则是已确认数据，不是 HPO 的类型化参数映射。执行时才替换当前 Trial flight、当前组的版本/名称/配置，以及当前观测窗口占位符。`query_method` 记录完整实际命令，但返回的原始冻结身份保留占位符。检查返回组属于本 Trial。不得重用参考 flight/版本 ID 或组标签、移除筛选、遗漏必需日期，或为取得数值改变人群。新的 Provider flag 属于数据，不是新 HPO schema 字段。

旧广告报告 argv builder 是旧类型化形状的可选辅助工具，不是新的身份合同，也不提供查询窗口。需要时阅读当前官方命令帮助和实际响应定义。query namespace 用于选择知识；不得把业务上的 realtime 新鲜度词解释成实时看板 namespace。Metrics-FE 保留其既有身份、当前组标签占位符及原始 URL。

在既有分析字段描述已尝试请求、观测时间、经过清理的结果/错误和剩余不确定性。执行回执保留在普通 Runtime trace。身份证据和值是否可用是两件事：真实候选无法区分、发现或查询失败、准确定位指标且成功取得完整响应但没有可用值，是不同的事实；按本 Job 的输出说明分别表达。成功元数据查询返回零匹配，只说明已查范围内没有匹配；身份仍未解析，不是歧义，也不是值查询前的观测缺失。以上任何状态都不是零值、成功、guardrail 通过或停止实验的许可。
